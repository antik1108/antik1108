## ⚡ What Drives Me

<table>
<tr>
<td width="50%" valign="top">

### 🐧 Linux & Operating Systems
Processes, memory, scheduling, file systems, the boot path. I want to know what happens between pressing Enter and the CPU doing the work.

### 🌐 Networking
Protocols, packet flow, architecture, and how two machines actually agree to talk. TCP/IP is a story I enjoy retelling.

### 🛡️ Cybersecurity
Vulnerabilities, system hardening, and defensive fundamentals. You can't defend what you don't understand, so I start from the internals.

</td>
<td width="50%" valign="top">

### ☁️ DevOps & Infrastructure
Containers, automation, deployments, reliable systems. Software isn't done until it runs well in the real world.

### 🧠 Core CS
C, computer architecture, data structures, algorithms. The boring stuff that makes everything else obvious.

### 🚀 Startups & Leadership
Building from zero, taking ownership, bringing structure to messy ideas, and turning plans into execution with a team.

</td>
</tr>
</table>
